Hangman Word Guessing Game 🎮

About the Project

The Hangman Word Guessing Game is a simple, interactive Python project developed as part of my Datheon Python Programming Internship.

The player tries to guess a randomly selected English word one letter at a time, with a maximum of six incorrect guesses.

Features

- Random word selection from an external text file.
- Interactive letter-guessing gameplay.
- Displays correctly guessed letters and hidden letters.
- Tracks incorrect guesses.
- Prevents repeated guesses.
- Validates user input.
- Displays Hangman graphics.
- Shows win and game-over messages.

Technologies Used

- Python 3
- Python standard libraries: "random" and "pathlib"
- Text-file handling

Project Files

- "hangman.py" — Main game program.
- "google-10000-english-no-swears.txt" — Word list used by the game.

How to Run

Prerequisites

Install Python 3 on your computer.

Steps

1. Clone or download this repository.
2. Make sure both project files are in the same folder.
3. Open a terminal in that folder.
4. Run the following command:

python hangman.py

How to Play

1. Run the program.
2. Enter one letter when prompted.
3. Correct guesses reveal the matching letters.
4. Incorrect guesses reduce your remaining attempts.
5. Guess the word before you reach six incorrect guesses to win.
