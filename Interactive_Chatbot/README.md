Task 4: Rule-Based Interactive Terminal Assistant

Project Description

This project is a rule-based interactive chatbot developed using Python. It responds to greetings and answers frequently asked questions using information stored in a JSON file.

Features

- Responds to greetings.
- Loads FAQ questions and answers from "sample_faq.json".
- Uses approximate text matching to identify questions.
- Displays a fallback response for unknown questions.
- Allows users to exit by typing "bye", "exit", or "quit".

Technologies Used

- Python
- JSON
- difflib module

Project Files

- "chatbot.py" – Main chatbot program.
- "sample_faq.json" – Contains greetings and FAQ data.
- "screenshots/" – Contains screenshots of testing.

How to Run

1. Make sure Python is installed.
2. Keep "chatbot.py" and "sample_faq.json" in the same folder.
3. Open the terminal in the project folder.
4. Run:

python chatbot.py

Testing

The chatbot was tested with greetings, FAQ questions, unknown questions, and exit commands.
