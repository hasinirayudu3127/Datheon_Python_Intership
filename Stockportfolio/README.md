Stock Portfolio Performance Tracker

About the Project

The Stock Portfolio Performance Tracker is a Python-based application developed as part of the Datheon Python Programming Internship. It calculates the total investment, current portfolio value, profit or loss, and percentage return for stock holdings.

Features

- Tracks multiple stock holdings.
- Calculates the invested amount for each stock.
- Calculates current market value using the prices provided in the program.
- Computes profit or loss for each holding.
- Calculates percentage return and overall portfolio performance.
- Exports portfolio results to a CSV file.
- Displays portfolio calculations in a formatted console table.

Technologies Used

- Python 3
- CSV module
- pathlib module

Project Files

- "portfolio.py" — Main Python program.
- "portfolio_summary.csv" — Generated portfolio report.
- "screenshots/" — Screenshots of the program output and CSV report.

How to Run

1. Install Python 3.

2. Open the project folder in Visual Studio Code.

3. Open the terminal.

4. Run the following command:
   
   "python portfolio.py"

5. View the results in the terminal.

6. Open "portfolio_summary.csv" to view the saved report.

Sample Data

The program currently uses sample stock prices and share quantities defined in the Python code. The results are for demonstration purposes and do not represent real-time stock market data.
